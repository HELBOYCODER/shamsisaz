# شمسی‌ساز ☀️ — ShamsiSaz

**یک دکمه، کل تقویم گوشی شمسی می‌شود**

> تبدیل خودکار همهٔ رویدادهای میلادی به تاریخ شمسی (جلالی) — مخصوص سامسونگ و شیائومی، روی همهٔ اندرویدها

[![Build APK](https://github.com/HELBOYCODER/shamsisaz/actions/workflows/build-apk.yml/badge.svg)](https://github.com/HELBOYCODER/shamsisaz/actions/workflows/build-apk.yml)

## ✨ قابلیت‌ها

| قابلیت | توضیح |
|--------|-------|
| 🪄 **یک دکمه جادویی** | همهٔ تقویم‌ها یک‌جا به شمسی |
| ⚙️ **از تنظیمات سیستم** | دکمهٔ «باز کردن تنظیمات سیستم» → زبان فارسی → کل گوشی شمسی |
| 📱 **سامسونگ + شیائومی** | One UI و MIUI — هر دو از CalendarProvider استاندارد |
| 🔍 **پیش‌نمایش** | قبل از تبدیل ببین چه می‌شود |
| ↩️ **بازگردانی** | یک لمس برگشت به میلادی |
| 📶 **آفلاین** | بدون اینترنت، بدون سرور |
| 🧩 **Quick Tile** | کاشی پنل نوتیفیکیشن — از بالا بکش و بزن |

## 📲 نصب

1. از [Releases](../../releases) آخرین `ShamsiSaz-vX.X.apk` را دانلود کن
2. روی گوشی نصب کن (Allow unknown sources)
3. اپ را باز کن → دسترسی تقویم را بده → **✨ تبدیل کل تقویم به شمسی**

## ⚙️ تبدیل کل گوشی از تنظیمات

برای اینکه **کل سیستم** شمسی شود (نه فقط رویدادها):

- **سامسونگ:** تنظیمات → مدیریت عمومی → زبان → **فارسی** را به بالا بکش
- **شیائومی:** تنظیمات → زبان و منطقه → **فارسی**
- داخل اپ دکمهٔ **«باز کردن تنظیمات سیستم»** مستقیم می‌برد

## 🔧 فنی

- `JalaliConverter` — الگوریتم 33 ساله، بدون وابستگی
- `CalendarConverter` — از `CalendarContract` استاندارد (همهٔ برندها)
- `ShamsiTileService` — Quick Settings Tile (API 24+)
- `minSdk 24` — اندروید ۷ به بالا
- Kotlin + Material 3 + ViewBinding
